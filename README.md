# 纸上坦克 · Paper Tanks

在草稿纸上进行的 15 × 15 回合制坦克战。纯前端 H5，无框架、无构建步骤，电脑和手机浏览器都能直接游玩，也可以安装为 PWA 离线运行。

> **AI 生成声明**
>
> 本项目的游戏代码、界面、AI 逻辑与文档由 AI 辅助生成；音效为第三方素材，图标由脚本程序生成。项目仅供学习与娱乐使用。

## 特性

- 15 × 15 棋盘，红蓝双方轮流行动
- 坦克、火炮、反坦克炮、步兵，以及摩托化变体
- 基地与哨站部署、哨站防御攻击、火炮溅射、反坦克炮克制
- 人机对战（普通 / 困难）与双人同屏
- 手机端适配：安全区、触控目标、底部固定“结束回合”
- 可安装 PWA：离线缓存 HTML/CSS/JS 与全部音效
- AI 调试面板：自对弈训练、棋力训练、玩家操作学习、控制区可视化

## 快速开始

### 直接打开

用浏览器打开 `index.html` 即可开始。音效、PWA 安装和离线缓存建议通过 HTTP(S) 访问。

### 本地服务器

需要 Node.js：

```bash
npm start
# 或
node server.js
```

启动后访问：

- 电脑：`http://localhost:8080`
- 手机：与电脑连接同一 Wi-Fi，打开终端打印的局域网地址，例如 `http://192.168.1.10:8080`

如果手机打不开，请允许 Node.js 通过 Windows 防火墙，或放行 8080 端口。

## 玩法

1. 开始界面选择“人机对战”或“双人同屏”。
2. 每回合获得 6 点建造值。
3. 点击建造卡片，再点击基地或哨站周围的空格部署单位。
4. 点击己方单位或建筑选中，再点击蓝格移动、红圈攻击。
5. 点击“结束回合”把行动权交给对方。

详细规则见游戏内“规则说明”。

### 操作

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 选择 / 行动 | 鼠标点击 | 手指点击 |
| 取消 | `Esc` | 点空白处或重新选择 |
| 结束回合 | `Enter` 或按钮 | 底部固定按钮 |
| 建造 | 侧栏卡片 → 棋盘空格 | 向下滚动到指挥所 → 卡片 → 棋盘空格 |

## 部署到 GitHub Pages

本项目是纯静态站点，不需要后端。

1. 新建 GitHub 仓库。
2. 上传项目根目录下的文件（不要只上传 `paper-tanks-h5.zip`，请解压后上传）。
3. 进入仓库 **Settings → Pages**。
4. **Build and deployment** 选择 **Deploy from a branch**。
5. 分支选择 `main`，目录选择 `/ (root)`，保存。
6. 等待部署完成，访问 `https://<用户名>.github.io/<仓库名>/`。

所有资源都使用相对路径，因此部署在仓库子路径下也能正常工作。`server.js` 只用于本地预览，GitHub Pages 会忽略它。

部署到 Netlify / Cloudflare Pages 等静态托管也可以直接把项目目录拖入即可。

## PWA 与离线

- `manifest.webmanifest`：应用名称、图标、启动方式
- `sw.js`：缓存页面、脚本、样式、图标和全部音效
- `icons/`：应用图标

安装方式：

- Android Chrome：菜单 → 安装应用 / 添加到主屏幕
- iPhone Safari：分享 → 添加到主屏幕

Service Worker 和安装能力需要 **HTTPS 或 localhost**。局域网 HTTP 可以正常游玩，但可能无法离线缓存或安装。

## 项目结构

```text
paper-tanks/
├── index.html              # 页面结构
├── style.css               # 界面、响应式、移动端适配
├── game.js                 # 游戏逻辑、渲染、AI 与训练
├── manifest.webmanifest    # PWA 清单
├── sw.js                   # Service Worker 离线缓存
├── server.js               # 本地静态服务器（零依赖）
├── package.json
├── icons/                  # PWA / 主屏幕图标
└── resource/sound/         # BGM 与音效
```

## 技术说明

- 原生 HTML / CSS / JavaScript，无第三方运行时依赖
- Canvas 2D 渲染棋盘与单位
- 音频使用 `<audio>` 播放
- 游戏设置、AI 策略与训练统计保存在浏览器 `localStorage`
- 调试面板数据可通过 JSON 导出 / 导入

## AI 调试

在游戏内点击“规则说明”旁的 **AI 调试** 可以打开：

- 快速自对弈训练与策略参数扰动
- 棋力训练：15 × 15 对称开局，统计各兵种在不同敌方火力下的输出与存活
- 玩家操作学习：识别玩家的建造、移动、攻击偏好，按全局与局部表现决定是否混入 AI 策略
- 控制区、潜在火力与阶段可视化

训练与统计数据只保存在本地浏览器中，不会上传。
